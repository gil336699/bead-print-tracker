Bead Print Tracker

How it works
  • Beads are grouped by color across all characters, so each color prints together.
  • When a plate finishes, press Plate printed, or tap the plate square on its color.
  • Tap a green plate to undo it.
  • Printed some beads before using this? Type the number in Already printed on that color.
  • Plate size changes how many beads go on the plates you haven't printed yet.
  • Everyone with the share link sees and edits the same progress.
